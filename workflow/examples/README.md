# Worked examples

Each file is a complete pipeline generated by `workflow-recommend` from a one-line
experiment description. They are regenerated by `examples/generate.py` so they stay
in sync with the knowledge base and engine.

| Example | Experiment type | Platform | What it exercises |
|---|---|---|---|
| [01 — kidney 3D](example_01_kidney_3d_visium.md) | 3D organ mapping | 10x Visium | Serial-section alignment (PASTE2 + Sutura Align refinement), spot deconvolution instead of cell typing, batch integration across 12 sections |
| [02 — breast tumor](example_02_breast_tumor_xenium.md) | Tumor architecture | Xenium | Cell segmentation (imaging), per-cell typing, spatial niches, ligand-receptor communication; no deconvolution |
| [03 — developmental series](example_03_developmental_merscope.md) | Developmental time series | MERSCOPE | Cross-timepoint integration with the over-correction warning; expression-space integration preferred over spatial registration across stages |
| [04 — disease vs control](example_04_disease_control_visiumhd.md) | Disease vs control | Visium HD | bin2cell segmentation, pseudobulk DE (PyDESeq2) with pseudo-replication warning, "don't correct away the effect" warning |
| [05 — liver atlas](example_05_liver_atlas_cosmx.md) | Atlas building | CosMx | Multi-donor harmonization, reference-based annotation (reference present, so no missing-reference warning) |
| [06 — whole embryo](example_06_whole_embryo_stereoseq.md) | Single-section survey | Stereo-seq | Native Stereopy toolkit for a format scanpy can't read; single section so no alignment/batch |

## How each was produced

```bash
python workflow/workflow-recommend -o examples/example_01_kidney_3d_visium.md \
  "3D organ mapping of human kidney, 10x Visium, 12 serial sections, want cell types and spatial domains"
```

Regenerate all of them at once:

```bash
python workflow/examples/generate.py
```

## What to notice

- **Segmentation and batch correction are never claimed as "solved."** Every such
  step is tagged `⚠️` / `expert judgment required` and carries an honest note about
  its failure modes.
- **The recommendation adapts to the platform.** Spot platforms (Visium) get
  deconvolution; imaging platforms (Xenium, MERSCOPE, CosMx) get segmentation +
  per-cell typing; Visium HD and Stereo-seq get their platform-native tooling.
- **The design changes the statistics.** Disease-vs-control leads with pseudobulk DE,
  not per-spot DE, and warns about pseudo-replication and correcting-away the effect.
- **Our own aligner is described honestly** — it routes to the best existing method
  and offers a gated refinement, and it does not claim to solve distortion or tears.
