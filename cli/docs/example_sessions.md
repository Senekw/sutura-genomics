# Sutura CLI - real local-model sessions

Generated by driving the agent loop with a local Ollama model (**llama3.2:3b**), no API key, no data egress. The planner only ever receives dataset *metadata* (names, spot/gene counts), never expression values. Weak-model plans that go out-of-vocabulary are corrected by the deterministic rule planner.
